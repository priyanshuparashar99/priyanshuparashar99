### What I've been building

#### ⚡ [mailmind](https://github.com/priyanshuparashar99/mailmind)
Autonomous email ingestion, semantic classification, and action agent built for high reliability.
- **Agent Architecture**: LangGraph `StateGraph` with async PostgreSQL persistence (`AsyncPostgresSaver`)
- **Ingestion & Safety**: Resend inbound webhooks with Svix verification, structured LLM classification, and HITL pause/resume gates
- **Tech Stack**: Python, FastAPI, Next.js 16, Tailwind CSS v4, Docker Compose

Multilingual legal AI assistant providing citation-grounded answers and structured action plans.
- **RAG Pipeline**: Dense vector search via FAISS & SentenceTransformers with query decomposition
- **Interface & i18n**: Full English/Hindi dynamic toggle, interactive legal library, and markdown-driven UX
- **Tech Stack**: LangChain, FastAPI, Next.js 15, Pydantic v2
